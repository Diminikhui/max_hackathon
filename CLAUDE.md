# Инструкции для Claude

Единые правила проекта находятся в [TEAM_GUIDE.md](TEAM_GUIDE.md). Перед работой прочитай их, Issue текущей задачи и связанные архитектурные решения.

Работай только в выделенной ветке и отдельном worktree. Не изменяй несвязанные файлы, не добавляй секреты и не расширяй границы MVP без решения команды. Перед передачей результата выполни доступные проверки и перечисли изменённые файлы, способ проверки и риски.

Не создавай и не отправляй коммит, не открывай и не объединяй Pull Request, если пользователь не поручил это явно. Новые переменные окружения документируй в `.env.example` без реальных значений.
