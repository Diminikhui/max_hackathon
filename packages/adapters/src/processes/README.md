# Лента статусов процессов (4-03)

Модуль задаёт локальный контракт `ProcessStatus`, порт источника и модельные адаптеры ФНС, Роспотребнадзора и МЧС.
Все модельные источники и уведомления имеют `isModel: true`. `ProcessStatusFeed.refresh()` сравнивает новое состояние с
репозиторием и возвращает ровно одно уведомление на переход; `dedupKey` защищает от повторной выдачи того же перехода.

`refresh()` возвращает `{ notifications, unavailable }`. Если ведомство не ответило, опрос остальных продолжается, а
источник попадает в `unavailable` с причиной: пользователю нужно показать «данные недоступны», а не «статус не
изменился». В тексте уведомления статусы выводятся по-русски (`PROCESS_STATUS_LABELS`), сырые коды туда не попадают.

Для постоянной эксплуатации реализуйте `ProcessStatusRepository` в storage. Встроенный
`MemoryProcessStatusRepository` предназначен только для модельного демо и тестов и теряет состояние при перезапуске.
