# Справочники

## ОКВЭД2

`okved2-2026-08-01.csv` — неизменённая выгрузка официального открытого набора Росстата
«Общероссийский классификатор видов экономической деятельности (ОКВЭД2)».

- источник: <https://rosstat.gov.ru/opendata/7708234640-okvedva>;
- файл источника: `data-20260801T1408-structure-20180402T1704.csv`;
- владелец: Федеральная служба государственной статистики;
- дата изменения набора: 2026-08-01, учтены изменения по 89/2026;
- заявленная дата актуальности: 2026-12-31;
- SHA-256 исходного файла: `7c6f395725867a93c6c3b34113b8896d28b8690431ba34ab8f3757d0643fc5f8`.

Карточка действующего классификатора ОК 029-2014 (КДЕС Ред. 2) опубликована
[Росстандартом](https://protect.gost.ru/classificators/details/62840d4b-4fcf-49cd-8416-991e6efc77d3).

Выгрузка хранится в UTF-8 и содержит три поля: буквенный раздел, код и наименование.
Для чтения используйте `parseOkvedCsv`, для иерархии и префиксного поиска — `OkvedReference`
из `@max-hackathon/domain`. При обновлении замените снимок целиком, зафиксируйте дату и новую
контрольную сумму; TLS-проверку не отключайте, сертификат НУЦ передавайте только процессу загрузки.
