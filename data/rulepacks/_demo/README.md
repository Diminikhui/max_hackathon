# Демо-изменение (K-29) — МОДЕЛЬНЫЕ ДАННЫЕ

Заранее подготовленная следующая версия модельного пакета. Её публикует кнопка бота «🧪 Показать пример изменения (модельное)», чтобы проверяющий увидел уведомление об изменении, не дожидаясь реального изменения законодательства.

| Что | Значение |
| --- | --- |
| Файл | `k28-model-v2.json`, `packId: k28-model`, `packVersion: 2`, `isModel: true` |
| Предыдущая версия | `data/fixtures/k28-rulepack-v1.json` — её загружают в хранилище при запуске демо-стенда |
| Изменение | добавлена `k28.water-marking` — «маркировка упакованной воды в Москве» (ОКВЭД 56 и регион 77) |
| Кого касается | `k28-cafe-msk` (ИНН `7700000016`) и `k28-cafe-bad-data` (`7700000030`); остальным модельным компаниям — нет |

**Запись вымышлена** и не является юридическим утверждением: она иллюстрирует механизм уведомления. Файл совпадает с `data/fixtures/k28-rulepack-v2.json` (это проверяет тест `apps/bot/test/flows/demo/pack.test.ts`), поэтому ожидаемые статусы из `k28-expected.json` верны и для демо-триггера. Пакет проходит валидатор K-15c:

```bash
node tools/rulepack-validate/rulepack-validate.mjs data/rulepacks/_demo/k28-model-v2.json
```

Файл не устанавливается в рабочий реестр `data/rulepacks/installed`: его публикует только демо-триггер, и только поверх модельного пакета `k28-model`. Реальные пакеты A и B демо-триггер не трогает.

## Шаг сценария проверки

1. Введите в боте модельный ИНН `7700000016` (кофейня в Москве) и подтвердите профиль.
2. Нажмите «🧪 Показать пример изменения (модельное)».
3. Бот сразу отвечает: что изменилось (пакет `k28-model` v1 → v2, добавлена обязанность), почему это касается компании (основной ОКВЭД 56.10 и регион 77 — условия выполнены), ссылка на первоисточник и пометка «модельное изменение».
4. Отдельным сообщением приходит уведомление контура рассылки: «🔔 Изменение: обязанность · МОДЕЛЬНЫЕ ДАННЫЕ … Требование стало применяться к вашей компании», с первоисточником и пометкой об автоматической обработке.
5. Нажмите кнопку ещё раз: ответ тот же, второе уведомление не приходит.
6. Для автосервиса `7700000023` бот честно отвечает, что изменение компании не касается (ОКВЭД 56 не выполнено), и подсказывает ИНН кофейни.

Как устроен сценарий — [apps/bot/src/flows/demo/README.md](../../../apps/bot/src/flows/demo/README.md).
