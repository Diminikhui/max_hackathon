# Пакет правил B — автосервис

`autoservice-federal-v1.json` — тонкий исполняемый пакет из семи федеральных
обязанностей для направления B, ОКВЭД `45.2`. Он собран вручную по официальным
источникам и совместим с контрактами rulepack K-15a/K-15b.

Пакет не является модельным: записи описывают проверенные правовые основания.
Модельным остаётся профиль для прогона — `k28-autoservice-msk` из
`data/fixtures/k28-companies.json` (ИНН `7700000023`). Автоматическая оценка
применимости не является юридической консультацией; интерфейс обязан показывать
официальные ссылки и пометку об автоматической обработке.

## Состав

- информация для потребителя, договор и приёмо-сдаточный акт по действующим с
  1 сентября 2025 года Правилам № 780;
- применение ККТ;
- охрана труда при наличии работников;
- паспортизация отходов I–IV классов опасности;
- противопожарный режим.

Все записи содержат источник и дату ручной проверки `2026-09-25`. Использованы
только сайты органов власти: Официальный интернет-портал правовой информации,
Роспотребнадзор, ФНС, Минтруд, Росприроднадзор и МЧС.

## Граница покрытия

У записей стоит `coverage: partial`, потому что профиль сейчас не содержит
фактов о работе именно с потребителями, способе расчёта, передаче автомобиля,
видах образующихся отходов, процессах и характеристиках помещения. ОКВЭД
показывает отраслевую релевантность, но не доказывает все юридические условия.
Такие записи должны давать `needs_review`, а не безусловное `applies`.

Срок действия Правил по охране труда № 871н продлён до 1 сентября 2027 года;
пакет нужно пересмотреть до `2027-08-31`. Правила противопожарного режима и
другие основания также проверяются перед выпуском следующей версии пакета.

## Проверка

После `pnpm install` из корня репозитория:

```bash
node tools/rulepack-validate/rulepack-validate.mjs \
  data/rulepacks/b/autoservice-federal-v1.json
```

Валидатор проверяет JSON Schema и семантические инварианты: совпадение
`packId`/версий, уникальность идентификаторов, периоды действия и маркировку
модельных данных.
