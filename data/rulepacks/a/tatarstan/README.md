# Региональное дополнение: Республика Татарстан

`foodservice-tatarstan-v1.json` — отдельный исполняемый пакет для организаций
общепита с ОКВЭД `56` и кодом региона `16`. Он не заменяет федеральный пакет
[`../foodservice-federal-v1.json`](../foodservice-federal-v1.json): при публикации
нужно установить оба файла. Тогда компания из Татарстана получает федеральные
записи и две региональные записи, которые покрывают четыре отличия:

1. допустимые типы заведений для продажи пива, сидра, пуаре и медовухи;
2. запрет продажи алкоголя с 22:00 до 10:00 в объектах общепита в
   многоквартирных домах и на прилегающих территориях, кроме ресторанов;
3. повышенную минимальную площадь зала для продажи алкоголя в таких объектах;
4. запрет продажи энергетиков в зданиях образования, медицины, культуры и
   спорта.

Содержательные поля обеих записей перенесены из проверенного эталона
[`../../_golden/a/checklist.yaml`](../../_golden/a/checklist.yaml) и имеют
`coverage: partial`: текущий профиль не содержит тип заведения, расположение в
многоквартирном доме, площадь зала и факт продажи энергетиков. Поэтому пакет
сообщает о требовании и необходимости проверки, но не делает безусловный
юридический вывод. Автоматическая оценка применимости не является юридической
консультацией; интерфейс обязан показывать официальные ссылки и пометку об
автоматической обработке.

## Источники

- [Закон Республики Татарстан от 06.03.2015 № 10-ЗРТ](https://pravo.tatarstan.ru/gossov/zakon.htm?npa_id=1425),
  статья 2;
- [Закон Республики Татарстан от 26.07.2024 № 59-ЗРТ](https://pravo.tatarstan.ru/gossov/zakon.htm?npa_id=1446691),
  изменения, действующие с 01.03.2025;
- [Закон Республики Татарстан от 03.01.2026 № 5-ЗРТ](https://pravo.tatarstan.ru/gossov/zakon.htm?npa_id=1773674),
  статьи 3 и 5, действует с 01.09.2026.

Тексты сверены на официальном портале правовой информации Республики Татарстан
27.09.2026. Изменения после этой даты пакет не учитывает.

## Проверка

Из корня репозитория:

```bash
node tools/rulepack-validate/rulepack-validate.mjs \
  data/rulepacks/a/tatarstan/foodservice-tatarstan-v1.json
```

Для воспроизводимой проверки совместного подключения установите федеральный и
региональный пакеты в один временный реестр:

```bash
RULEPACK_DIRECTORY=/tmp/max-rulepacks node tools/pack/pack.mjs add \
  data/rulepacks/a/foodservice-federal-v1.json
RULEPACK_DIRECTORY=/tmp/max-rulepacks node tools/pack/pack.mjs add \
  data/rulepacks/a/tatarstan/foodservice-tatarstan-v1.json
```
