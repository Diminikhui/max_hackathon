# Возможности для общепита

`foodservice-opportunities-federal-v1.json` — отдельный федеральный пакет из
четырёх записей `kind: opportunity` для направления A (ОКВЭД `56`). При
публикации вместе с основным пакетом перечень может вывести эти записи отдельным
блоком «что можно получить», не смешивая их с обязанностями.

Пакет содержит:

- общее освобождение услуг общепита от НДС;
- временное освобождение от НДС для отдельных плательщиков УСН и ПСН с
  01.04.2026 по 31.12.2026;
- пониженный тариф страховых взносов для субъектов МСП в сфере общепита;
- возможность применять ПСН для ИП, если режим введён законом региона.

## Граница достоверности

Это не рекомендации по выбору налогового режима и не юридическое заключение.
Записи сообщают о предусмотренной законом возможности, содержат официальный
первоисточник и дату получения сведений. У всех записей `coverage: partial`:
профиль компании пока не содержит всех юридически значимых показателей — доли и
суммы доходов, средней зарплаты, организационно-правовой формы, площади зала и
региональных ограничений. Поэтому совпадение формализованных условий не должно
давать результат выше «требуется проверка».

Условия проверены по материалам ФНС и официально опубликованным актам по
состоянию на 27.09.2026. Временная льгота по НДС заканчивается 31.12.2026;
остальные записи нужно перепроверять при изменении НК РФ и регионального
законодательства.

## Проверка

После `pnpm install` из корня репозитория:

```bash
node tools/rulepack-validate/rulepack-validate.mjs \
  data/rulepacks/a/opportunities/foodservice-opportunities-federal-v1.json
```
