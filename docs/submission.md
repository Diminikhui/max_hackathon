## 6. Решение о готовности

Пакет готов к отправке только когда:

1. во всех разделах выше нет незакрытых обязательных `[ ]`;
2. тег, SHA, PDF и проверяемое развёртывание относятся к одной версии;
3. чистый прогон и GitHub Actions зелёные для этого SHA;
4. секреты и реальные персональные данные не попали в Git;
5. ответственный участник вручную сверил поля актуальной формы организаторов с
   этим документом.

До выполнения этих условий формулировка статуса — **«чеклист подготовлен,
пакет не зафиксирован»**, а не «готово к сдаче».
