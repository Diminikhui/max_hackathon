# Безопасность репозитория

Этот документ фиксирует обязательные меры для кода и CI. Проверки выполняются в workflow `Repository checks` для каждого Pull Request и push в `main`.

## Секреты

- Токены, пароли, ключи API, приватные ключи и реальные данные компаний не коммитятся.
- Локальные значения хранятся в игнорируемом `.env`; в репозитории остаётся только `.env.example` с пустыми или явно модельными значениями.
- В CI секреты задаются через GitHub Actions Secrets и не печатаются в логи.
- Gitleaks проверяет историю Git в CI. Если секрет попал в commit, его нужно сначала отозвать/ротировать, а затем удалить из истории. Простого удаления из последующего commit недостаточно.

Ложное срабатывание не исправляют подменой сканера или глобальным исключением. Нужно убедиться, что это тестовое значение, и добавить точечное исключение с обоснованием в отдельном PR.

## Зависимости и лицензии

- Node.js и pnpm зафиксированы через `.nvmrc` и `packageManager`.
- Точное дерево пакетов хранит `pnpm-lock.yaml`; CI устанавливает его только с `--frozen-lockfile`. Изменение manifest без обновлённого lockfile ломает CI.
- Внешние GitHub Actions зафиксированы на неизменяемые commit SHA. При обновлении рядом с SHA сохраняют комментарий с major-версией.
- CI строит полный отчёт `pnpm licenses list --json`. Разрешены только явно проверенные permissive лицензии и MPL-2.0. Новый тип лицензии останавливает CI и требует ручного разбора. Лицензию добавляют в allowlist только вместе с обоснованием в PR.

## TLS

Проверку TLS нельзя отключать ни в коде, ни в скриптах, ни в CI. Для контура MAX корневой сертификат НУЦ Минцифры подключается только к процессу приложения через `NODE_EXTRA_CA_CERTS`; см. [ADR-0003](decisions/0003-issued-bot-and-hackathon-contour.md) и [инструкцию по сертификату](../certs/README.md).

CI блокирует типовые обходы для Node.js, Python, Go, curl и wget. Markdown и сам workflow сканера исключены, потому что они содержат описания самих запретов. Остальные workflow сканируются. Если сканер не узнаёт новую технологию, её шаблон добавляют в эту проверку, а не в список исключений.

## Локальная проверка

```bash
pnpm install --frozen-lockfile
pnpm licenses list --json
./scripts/verify-repository.sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

После изменения security workflow нужно также проверить сам YAML и дождаться всех job в Pull Request.
