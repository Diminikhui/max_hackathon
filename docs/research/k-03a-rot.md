# K-03a. ФГИС «Реестр обязательных требований»: доступ и пригодность для интеграции

Проверено 25.09.2026. Цель — выяснить, можно ли без учётных данных получать записи ФГИС РОТ для профиля компании и связывать их с ОКВЭД. Вывод относится к **автоматическому** адаптеру K-13b, а не к возможности человека открыть публичный портал.

## Вывод

**Real технически возможен; для MVP — fixture по решению команды; для масштабирования — черновики пакетов из ФГИС РОТ с проверкой человеком.**

Из окружения этой проверки (25.09.2026) `ot.gov.ru` не ответил, но команда 23.09.2026 получила доступ из другой сети ([предложение, п. «Проверка ФГИС РОТ»](../proposals/2026-09-23-gaps-and-proposals.md)): портал отдаёт JSON без авторизации через **внутренний API без опубликованной спецификации**. Серверного фильтра по ОКВЭД нет, значит real-адаптер — это офлайн-выгрузка (порядка 7 ГБ, несколько часов) и локальный фильтр по `activitySubtype`. Опора на недокументированный API и неполная разметка ОКВЭД требуют решения команды — тот же критерий, что для ЕРКНМ (K-03b). В MVP live-адаптеры ФГИС РОТ и ЕРКНМ отнесены к «Won't до сдачи» ([roadmap, раздел 1](../roadmap.md); [ADR-0006](../decisions/0006-adopted-gap-proposals.md)), поэтому K-13a/K-13b используют помеченные модельные фикстуры **по решению, а не из-за недоступности**.

Росздравнадзор прямо указывает публичный портал `https://ot.gov.ru/mr` и наличие сведений о требованиях и ответственности. | [Постановление № 128 на сайте МВД](https://mvd.consultant.ru/documents/1057327), [официальный доклад Росздравнадзора, стр. 8](https://roszdravnadzor.gov.ru/i/upload/images/2025/2/25/1740477399.75673-1-2129426.pdf). Постановление на зеркале может не отражать позднейшие редакции; перед юридическим применением сверять [официальную публикацию](https://publication.pravo.gov.ru/Document/View/0001202102090035). |

Есть отдельные поля для категории лиц, акта, структурной единицы, вида контроля и органа. | [Официальный перечень Минздрава](https://minzdrav.gov.ru/poleznye-resursy/forma_perechney), обновлён 08.11.2023. Это **ведомственный HTML-перечень**, не доказательство формата ответа ФГИС РОТ. |
| Пример опубликованной строки | В строке № 1 перечня Минздрава указан акт № 811н, структурная единица «пункт 9» и ОКВЭД 21, 21.1, 21.2. | [Та же страница Минздрава](https://minzdrav.gov.ru/poleznye-resursy/forma_perechney). Снимок полей — [`k03a-observed-minzdrav-row.json`](../../data/fixtures/k03a-observed-minzdrav-row.json); актуальность обязанности **не проверялась**. |

Поисковый признак ОКВЭД не равен окончательному решению о применимости: в перечне отдельно указаны категории лиц, сфера контроля и структурные единицы акта. Код верхнего уровня может охватывать несколько подклассов. Для результата «применяется» нужны проверенные условия и актуальный первоисточник; при пробелах следует показывать `needs_review` или `out_of_coverage`.

## Проверка доступа и формата

| Проверка 25.09.2026 | Результат |
|---|---|
| `curl -I -L --max-time 15 https://ot.gov.ru/` с обычной проверкой TLS | Тайм-аут соединения, код `curl` 28; HTTP-ответ не получен. |
| Открытие `https://ot.gov.ru/` через веб-инструмент и встроенный браузер | Тайм-аут загрузки. |
| Проверка команды 23.09.2026 из другой сети | Геоблокировки нет. Тайм-аут и ошибка TLS — разные симптомы: при доступной сети запрос падает на сертификате Russian Trusted Sub CA (НУЦ Минцифры). `curl -k` и отключение TLS не нужны и запрещены: достаточно доверять корню Минцифры процессу (`NODE_EXTRA_CA_CERTS`, как в ADR-0003). |
| Машинный доступ (команда, 23.09.2026) | `POST https://ot.gov.ru/api/mandatoryRequirement/list`, тело `{"items":[],"paging":{"page":N,"count":100}}` → JSON без авторизации; всего около 542 536 требований, около 13 КБ на запись, 100 записей примерно за 5 с. Карточки: `GET /api/mandatoryRequirement/{id}` и `/card`. |
| Поля записи | `activitySubtype` (коды ОКВЭД, часто `00` — все виды деятельности), `categoriesOfPersons`, `publicRelationSpheres`, `controlTypes` (проверочные листы), `interestedFOIV`, `checkQuestion`. |
| Фильтрация и открытые данные | Серверный фильтр `activitySubtype=<код>` — тайм-аут шлюза 120 с; `queryLike` игнорируется. Набор открытых данных `7710474375-mrlist`: схема `/api/opendata/schemas/7710474375-mrlist/data.json` отдаётся, `/api/opendata/mrlist` отвечает 404. |
| Поиск официальной документации API и выгрузки на `ot.gov.ru`, государственных сайтах | В проверенных публикациях не найдено спецификации эндпоинтов, схемы JSON/XML, лимитов или лицензии повторного использования. Нельзя принимать неофициальные сетевые вызовы сторонних расширений за поддерживаемый API. |

**Формат ответа известен по наблюдению команды, но это внутренний API портала без опубликованной спецификации, лимитов и лицензии.** Парсер писать только по сохранённым фактическим ответам; TLS не обходить. Ближайший подтверждённый формат — HTML-таблица ведомственного перечня Минздрава. Её можно использовать как вспомогательный источник для ручной сверки, но нельзя выдавать за выгрузку ФГИС РОТ.

## Образцы для зависимых потоков

- [`k03a-observed-minzdrav-row.json`](../../data/fixtures/k03a-observed-minzdrav-row.json) — наблюдение из официальной HTML-таблицы, **не ответ API** и не подтверждение действующей обязанности.
- [`k03a-model-requirements.json`](../../data/fixtures/k03a-model-requirements.json) — полностью **модельные** записи `Requirement v1` для ОКВЭД 56 и 47. Их нельзя показывать как реальные обязательства.

## Что нужно для перехода K-13b к real

1. Из доступной сети открыть `https://ot.gov.ru/mr`, выбрать записи для ОКВЭД 56, 45.2 и 47 и сохранить URL карточек, дату и ответы штатного интерфейса с заголовками `Content-Type` (без cookie и персональных данных).
2. Получить у оператора или в официальной документации разрешённый способ машинного доступа, формат, пагинацию, лимиты и правила повторного использования. Если есть только публичный UI, отдельно оценить устойчивость и допустимость получения данных через него.
3. Сверить не менее 20 фактических записей с официальными текстами актов: идентификатор, ОКВЭД, категории лиц, период действия, структурную единицу и ссылку на первоисточник. Пустой или широкий код ОКВЭД не считать точным совпадением.
4. До этого K-13a/K-13b используют только помеченные модельные фикстуры и явно сообщают об отсутствии подтверждённого real-источника.

## Ограничения исследования

Из окружения этой проверки портал не ответил; сведения о доступе и формате взяты из проверки команды 23.09.2026 и повторно здесь не воспроизведены. Актуальность постановления № 128 и ведомственной строки после указанных дат отдельно не подтверждена.
