# Безопасность

Не публикуйте сведения об уязвимостях в открытом Issue. Сообщите владельцу репозитория напрямую и укажите затронутую версию, способ воспроизведения и возможное влияние.

## Секреты

Токены MAX, ключи LLM, пароли БД и ключи внешних сервисов хранятся только в локальном `.env` или GitHub Secrets. В репозитории допускается только `.env.example` с пустыми значениями.

Если секрет попал в Git, не ограничивайтесь удалением файла: немедленно отзовите или замените секрет, затем сообщите команде и очистите историю отдельной согласованной операцией.

Для демо используйте тестовые или синтетические данные. Не добавляйте реальные персональные данные и закрытые сведения компаний.
