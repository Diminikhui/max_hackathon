# Совместная работа

## Начало задачи

1. Выберите или создайте Issue с результатом и критериями приёмки.
2. Назначьте одного ответственного.
3. Создайте ветку от актуальной `origin/main` по правилам из [TEAM_GUIDE.md](TEAM_GUIDE.md).
4. Для каждого параллельного агента используйте отдельный worktree.

## Перед Pull Request

Запустите тесты, линтер и сборку, предусмотренные выбранным стеком. Проверьте diff на случайные файлы и секреты. Обновите документацию, если изменились запуск, API, конфигурация или поведение пользователя.

## Проверка Pull Request

Проверяющий воспроизводит изменение по описанию, оценивает соответствие Issue и границам MVP, проверяет обработку ошибок и отсутствие секретов. Автор отвечает на все замечания до слияния.

Используется Squash merge. Название PR должно подходить как сообщение итогового коммита.
