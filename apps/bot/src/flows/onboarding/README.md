# Сценарий онбординга (K-24a)

Обработчики маршрутов машины диалога K-22b от первого сообщения до главного меню: приветствие → ИНН → поиск компании (K-25b) → подтверждение профиля → меню.

## Подключение

```ts
const sessions = new InMemoryOnboardingSessions(); // для демо; в K-30b — хранилище с тем же портом
const { unrecognized, ...onboardingFlow } = createOnboardingFlow({
  profiles: new ProfileService({ source, repository }), // K-25b, подходит к порту ProfileGateway
  sessions,
});
const checklistFlow = createChecklistFlow({ checklist, companyOf: (dialogId) => sessions.companyOf(dialogId) });
const router = createDialogRouter<FlowReply>({ ...otherHandlers, ...onboardingFlow, ...checklistFlow });

// В обработчике транспорта K-22a:
const reply =
  dialogEvent === undefined
    ? await unrecognized({ dialogId, state }) // текст вместо ИНН и т. п.; undefined — экран другого сценария
    : (await router.dispatch({ dialogId, state, event: dialogEvent })).result;
// Сохранить reply.stateOverride ?? transition.state (для unrecognized — reply.stateOverride ?? state).
```

Сценарий отвечает за маршруты `show_welcome`, `request_inn`, `lookup_profile`, `confirm_profile`, `profile_not_found`, `profile_lookup_failed`, `show_menu`, `recover_current` и `reset_dialog`. Настройки уведомлений — K-24c, перечень — K-24b.

## Шаги

| Шаг | Состояние | Кнопки |
|---|---|---|
| «Начать» (`bot_started`, `/start`) | `awaiting_inn` | «↩️ В начало» |
| ИНН текстом («ИНН 7700 000 016» тоже годится) | `confirming_profile` | «✅ Всё верно», «✏️ Другой ИНН», «↩️ В начало» |
| «Всё верно» → `ProfileService.confirm` | `menu` | «📋 Мой перечень», «🔔 Уведомления», «🔄 Другая компания» |
| «🔄 Другая компания» (`edit_profile` из меню) | `awaiting_inn` | «↩️ В начало» — отмена: меню с прежней компанией; новая компания заменяет прежнюю только после «Всё верно» |

Поиск идёт внутри `lookup_profile`: машина K-22b за один `dispatch` делает один переход, поэтому следующее состояние (`profile_loaded` / `profile_not_found` / `profile_lookup_failed` из `loading_profile`) считается той же машиной и возвращается в `stateOverride`.

Карточка компании показывает название, ИНН, тип и известные поля профиля (ОКВЭД, регион, категория МСП, работники, алкоголь, налоговый режим). По каждому полю берётся один факт в порядке вычислителя K-16a: официальный, производный, заявленный. Заявленный помечается «по вашим словам», сценарные факты не показываются. Модельный профиль или источник помечаются «МОДЕЛЬНЫЕ ДАННЫЕ».

Найденный профиль хранится в `OnboardingSessions` до подтверждения. После подтверждения диалог привязывается к `companyId`: `sessions.companyOf` — порт `companyOf` сценария K-24b.

## Нештатные случаи

Каждый ответ содержит кнопки, которые машина примет в новом состоянии; тесты проверяют это на всех шагах.

| Случай | Ответ | Состояние |
|---|---|---|
| Текст вместо ИНН | «Это не похоже на ИНН» и подсказка | `awaiting_inn` |
| ИНН не прошёл проверку K-25a | Текст ошибки проверки и подсказка | `awaiting_inn` |
| Компания не найдена | Объяснение, просьба проверить номер | `awaiting_inn` |
| Источник недоступен или сервис бросил исключение | Просьба повторить | `awaiting_inn` |
| Ошибка сохранения профиля | Карточка снова, «Всё верно» ещё раз | `confirming_profile` |
| Текст или чужая кнопка на карточке | Карточка с подсказкой | `confirming_profile` |
| Подтверждение без найденного профиля (перезапуск бота) | «Данные компании устарели», ввод ИНН | `awaiting_inn` |
| Поиск прервался (`loading_profile` из прошлого процесса) | «Поиск прервался», ввод ИНН | `awaiting_inn` |
| Меню без привязанной компании | Приветствие «Сначала укажите ИНН» | `idle` |
| Устаревшая кнопка в карточке требования | Меню «Это действие устарело» | `menu` |
| Неизвестное сохранённое состояние | Приветствие «начнём сначала» | `idle` |
| Старая кнопка «Всё верно» в меню | Меню, профиль повторно не сохраняется | `menu` |

## Ограничения

- `InMemoryOnboardingSessions` живёт в памяти процесса: после перезапуска найденный профиль и привязка теряются, диалог просит ИНН заново. Постоянное хранение — при сборке контура K-30b.
- Правка отдельных полей профиля в диалоге не реализована: «Другой ИНН» ведёт к новому поиску. Уточнения полей — K-09 и мини-приложение (`ProfileService.declare`).
- Регион выводится кодом: справочник регионов боту не подключён.
