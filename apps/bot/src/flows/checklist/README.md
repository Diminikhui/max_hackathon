# Сценарий перечня (K-24b)

Обработчики маршрутов машины диалога K-22b `show_requirement_list` и `show_requirement_details`: перечень обязанностей компании и карточка записи.

## Подключение

```ts
const checklistFlow = createChecklistFlow({
  checklist: new ChecklistService({ profiles, requirements }), // K-26, подходит к порту ChecklistSource
  companyOf: async (dialogId) => sessions.companyOf(dialogId),  // компания после онбординга K-24a
});
const router = createDialogRouter<FlowReply>({ ...otherHandlers, ...checklistFlow });
```

Обработчик возвращает `FlowReply`: `text`, `buttons` (`NotificationButton` для отправителя K-21b), `sourceUrls`, `automated` и необязательный `stateOverride`. Если `stateOverride` задан, сценарий сохраняет его вместо `transition.state`.

## Перечень

- Счётчики всех пяти статусов: применяется, недостаточно данных, требуется проверка, вне покрытия, не применяется.
- Записи первых четырёх статусов — нумерованным списком по разделам. «Не применяется» — только количеством: иначе кафе увидело бы все записи автосервиса. Карточку такой записи можно открыть, если прийти к ней по id.
- Кнопки — номера записей («1», «2», …) и «🏠 Меню». Отправитель K-21b кладёт до 7 callback-кнопок в ряд, поэтому короткие номера читаются лучше заголовков.
- Внизу — дата расчёта и версии пакетов правил, пометки об автоматической обработке и модельных данных.

## Карточка

Шаблон K-23 `renderObligationCard`: статус, причина, кратко, срок, срок действия, дата проверки и первоисточник со ссылками. Кнопки — «← К перечню» и «🏠 Меню».

## Нештатные случаи

| Случай | Ответ | `stateOverride` |
|---|---|---|
| Диалог не знает компанию или профиль не найден | «Сначала укажите ИНН» и кнопка «Ввести ИНН» | `idle` |
| Кнопка из старого сообщения: записи нет в новой версии пакета | Актуальный перечень с пояснением | `requirement_list` |

Перечень строится заново при каждом показе, поэтому список и карточка всегда соответствуют последней версии пакета и профиля.
