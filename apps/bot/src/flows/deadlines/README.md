# «Что и когда делать»

Opt-in flow `BOT_FEATURES=deadlines` показывает результат готового `ActionQueueService`.
Он группирует `actions` по дате, а `undated` — по готовой причине `reason`; текст срока
не разбирается и новые даты в боте не вычисляются.

Длинная группа показывает три записи и кнопку «Ещё N» для перехода к её перечню.
Каждая видимая запись содержит исходный срок и ссылку на первоисточник. Сообщение
помечается модельным, если модельна компания (K-28) или хоть одна запись: очередь
действий несёт модельность только записей, поэтому бот узнаёт модельность компании
из перечня (`isModelCompany` в `createDeadlinesFlow`).
