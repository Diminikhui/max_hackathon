# «Что будет, если…»

Опциональный flow под `BOT_FEATURES=whatif`. В главном меню появляется одна кнопка, ведущая к четырём готовым
сценариям на известных фактах v1. Выбор вызывает переданный `ScenarioDeltaService`, показывает дельту обязанностей
и мер поддержки и не сохраняет сценарную копию профиля.

Flow использует собственные payload `whatif:*` и остаётся в состоянии основного меню. Для появившихся записей
переиспользуется обычный рендер карточки K-24b. Без зависимости `whatif` кнопки и обработчика payload нет.
