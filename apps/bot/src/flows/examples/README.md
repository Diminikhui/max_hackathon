# Модельные примеры на шаге ИНН

Опциональный сценарий под флагом `BOT_FEATURES=examples` добавляет на экран ввода ИНН три кнопки с
модельными компаниями K-28. Кнопка создаёт то же событие `submit_inn`, что и ручной ввод, поэтому поиск,
подтверждение профиля, перечень и уточнения работают обычным онбордингом.

`selectExampleCompanies` получает профили, реально загруженные в процесс, и исключает отсутствующие либо не
помеченные `isModel`. Без флага зависимость не передаётся в бот: кнопок нет, payload примера не обрабатывается.
