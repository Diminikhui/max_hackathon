# Экран перечня (2-03)

Экран создаёт сессию через `POST /api/v1/session` с `initData` из MAX Bridge, затем загружает
`GET /api/v1/checklist`. Токен сессии хранится только в памяти компонента.

Показываются все пять статусов применимости с числом записей, фильтр, раскрываемая карточка,
срок, дата проверки и кнопка первоисточника. Ссылка открывается через Bridge из `useApp().openLink`.

Вне MAX экран использует явно помеченный модельный перечень, содержащий по одной записи каждого
статуса. Это позволяет проверять web/mobile-вёрстку без настоящего `initData` и компании.
