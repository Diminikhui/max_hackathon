# Отбор и текст проектов regulation.gov.ru (K-18c)

`selectFeedProjects` объединяет три независимых сигнала по «ИЛИ»: сферу портала, фразу в заголовке и ведомство. Сферы — идентификаторы справочника regulation.gov.ru, **не коды ОКВЭД**. Результат всегда имеет статус `needs_review`: это ранний сигнал, а не юридическое заключение и не точная применимость.

```ts
const selected = selectFeedProjects(projects, [{
  id: "public-catering",
  sphereIds: [23],
  titleKeywords: ["общественного питания", "кафе", "ресторан*"],
  departments: ["Роспотребнадзор"],
}]);
```

Функция нормализует регистр, Unicode, `е`/`ё` и пунктуацию, возвращает все сработавшие сигналы и сортирует результат по ID. Суффикс `*` задаёт явный префикс одного слова (`ресторан*` покрывает словоформы); неявного стемминга нет. Пустые правила и дубли ID отвергаются вместо неявного выбора.

`loadProjectText` читает публичный `GetProjectStageInfo/{id}/{stage}` и извлекает только белый список текстовых полей. HTML превращается в инертный текст; `script`/`style` отбрасываются, глубина, число узлов и размер ограничены. Неизвестная форма ответа считается ошибкой источника, а не пустым успешным результатом. Текст внешнего документа остаётся недоверенными данными и не должен использоваться как инструкция для модели.

Контрольная выборка и ограничения описаны в `docs/research/k18c-feed-signal-filter.md`.
